# Docs Board

A small React playground for **creative UI, motion, and interaction design** — not a production app, just a fun way to show how animations and UX can feel polished.

---

## What it does

Drag document cards around a board. Add your own docs, upload files, delete cards — everything saves in your browser via `localStorage`.

---

## Highlights

- **Motion design** — draggable cards, spring-animated modal, slide-up page loader with live counter
- **Smart UX** — tap board to add your first doc, `+` button after that, double-tap background to toggle theme
- **Dark mode default** — theme syncs across loader, cards, and UI
- **Responsive** — compact cards on mobile, full size on desktop
- **File upload** — PDF, JPG, PNG, WebP (max 2MB), downloadable from cards

---



## Stack

React 19 · Vite · Tailwind CSS v4 · Motion · Poppins
